# 100,000 LKR Savings Tracker — Premium Android App

This is a native Android app project. It does not use a website or browser.

## Savings structure
- 100 × Rs. 500 = Rs. 50,000
- 150 × Rs. 200 = Rs. 30,000
- 100 × Rs. 100 = Rs. 10,000
- 200 × Rs. 50 = Rs. 10,000
- **Total = Rs. 100,000**
- **550 total boxes**

## How to build the APK
1. Install Android Studio.
2. Extract this ZIP.
3. Open the `LKRSavingsTrackerAndroidPremium` folder.
4. Let Android Studio finish Gradle and SDK setup.
5. Choose **Build > Build App Bundle(s) / APK(s) > Build APK(s)**.
6. The APK is usually created at:
   `app/build/outputs/apk/debug/app-debug.apk`
7. Copy that APK to your Android phone and install it.

The installed app works fully offline.
